# 快跑狗头 · 重制版

## 项目介绍

一个原生 JavaScript Canvas 生存躲避游戏，已完成从“Demo 级”到“可交付级”的整体重构升级。  
本版本重点优化了功能设计、界面设计和交互体验，适合直接给用户试玩与验收。

## 本次重构升级内容

### 1) 功能设计升级

- 引入完整游戏状态机：**准备 / 进行中 / 暂停 / 结束**
- 加入多难度系统：**休闲 / 标准 / 地狱**
- 关卡系统重做：倒计时结束自动进阶，关卡越高威胁越强
- 计分系统升级：实时得分 + 历史最高分 + 历史最高关卡持久化

### 2) 界面设计升级

- 重建信息架构：HUD 状态区 + 中央竞技场 + 右侧玩法引导
- 增加可视化指标：生命值、关卡倒计时、冲刺能量进度条
- 统一视觉风格：现代化深色主题、玻璃拟态面板、响应式布局

### 3) 交互体验升级

- 替换原始 `alert` 启动方式，提供按钮式完整流程
- 支持开始、暂停、继续、重开
- 新增即时 Toast 反馈、暂停遮罩提示、结束结算提示
- 页面失焦自动暂停，减少误操作导致的挫败感

## 快速开始

你可以直接用浏览器打开 `index.html` 运行。  
建议用本地静态服务器访问（避免部分浏览器策略差异）：

```bash
python3 -m http.server 8080
```

然后访问：`http://127.0.0.1:8080`

## 操作说明

- 移动：`W / A / S / D` 或方向键
- 冲刺：`Shift`
- 暂停 / 继续：`P` 或空格

## 难度说明

| 难度 | 适合人群 | 特点 |
| --- | --- | --- |
| 休闲 | 新手体验 | 血量更高、节奏更缓 |
| 标准 | 常规挑战 | 综合平衡，推荐默认 |
| 地狱 | 高玩挑战 | 敌球更多更快、容错更低 |
